# Jejak Hijau — Blog Environmental Campaign

Website kampanye edukasi lingkungan tentang pengurangan dan pemilahan sampah.

## Isi website
- `index.html`: beranda kampanye
- `kenali-isu.html`: edukasi sampah plastik, sampah tercampur, dan kebiasaan konsumsi
- `panduan-pilah.html`: panduan dasar pemilahan sampah
- `tantangan-7-hari.html`: checklist interaktif yang disimpan secara lokal di browser
- `tentang.html`: tujuan kampanye, teknologi, dan sumber belajar
- `assets/styles.css`: desain responsif
- `assets/script.js`: menu mobile dan checklist

## Teknologi
HTML, CSS, JavaScript. Tidak memerlukan framework atau proses build.

## Menjalankan secara lokal
Buka `index.html` di browser. Gambar memakai URL dari Unsplash sehingga memerlukan koneksi internet.

## Publikasi di GitHub Pages
1. Unggah semua file dan folder ke root repository.
2. Pastikan `index.html` ada di root repository dan folder `assets` tetap memiliki `styles.css` serta `script.js`.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Tunggu proses deployment selesai.

## Catatan isi
Artikel berisi edukasi umum. Periksa sumber resmi dan peraturan pengelolaan sampah setempat untuk informasi yang lebih spesifik. Jangan menambahkan angka statistik tanpa mencantumkan sumber dan tahun.

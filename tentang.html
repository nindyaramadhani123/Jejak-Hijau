Tentang kampanye

Pengetahuan yang baik seharusnya memudahkan kita bertindak.

Jejak Hijau adalah blog kampanye edukasi lingkungan yang mengajak pembaca memulai pengurangan dan pemilahan sampah dari kebiasaan sehari-hari.

← Kembali ke beranda

Tujuan Jejak Hijau

Blog ini dibuat sebagai kampanye sosial-lingkungan untuk membantu pembaca memahami masalah sampah dan menemukan langkah sederhana yang dapat dilakukan di rumah, kampus, maupun ruang publik.

Konten dirancang agar ringkas, mudah dibaca melalui ponsel, dan mendorong aksi nyata tanpa menyalahkan individu. Perubahan kebiasaan berjalan lebih baik ketika didukung fasilitas dan sistem pengelolaan sampah yang memadai.

Teknologi yang digunakan

Website ini dibuat menggunakan teknologi web terbuka: HTML untuk struktur halaman, CSS untuk desain responsif, dan JavaScript untuk menu serta checklist tantangan. Website dapat diakses melalui browser laptop maupun ponsel dan dapat dipublikasikan menggunakan GitHub Pages.

Sumber untuk belajar lebih lanjut

Artikel di blog ini merupakan materi edukasi umum. Untuk kebijakan, data, dan panduan yang lebih rinci, periksa sumber resmi berikut:

  • Kementerian Lingkungan Hidup Republik Indonesia — informasi dan kebijakan lingkungan nasional.
  • United Nations Environment Programme (UNEP) — sumber pengetahuan lingkungan global.
  • Sistem Informasi Pengelolaan Sampah Nasional (SIPSN) — informasi pengelolaan sampah Indonesia, jika data tersedia.
Catatan akademik: sebelum laporan dikumpulkan, tambahkan identitas anggota kelompok dan sesuaikan deskripsi proyek dengan instruksi dosen. Jika menggunakan data angka, tulis tahun dan sumbernya secara jelas.
